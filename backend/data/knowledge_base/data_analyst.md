# Data Analyst Knowledge Base

## Analytical Reasoning
Data analysts convert messy data into decisions. Strong analysis starts with a precise question, clear metric definitions, trustworthy data sources, and awareness of bias, missingness, outliers, and confounding factors.

## SQL And Data Cleaning
SQL work requires joins, aggregation, filtering, window functions, and validation of row-level assumptions. Data cleaning should check nulls, duplicates, type consistency, date ranges, category drift, and business-rule violations.

## Visualization And Storytelling
Dashboards should make comparison and action easy. Good analysts choose charts based on the question, avoid misleading scales, annotate important changes, and connect findings to business impact.

## Experimentation And Metrics
Experiments require clear hypotheses, guardrail metrics, segmentation, and statistical caution. Candidates should explain when a metric is actionable, when it is a proxy, and how they would validate a surprising result.
