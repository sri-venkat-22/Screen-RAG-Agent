# Testing Engineer Knowledge Base

## Test Strategy
Testing engineers create confidence in releases by combining unit, integration, end-to-end, exploratory, performance, security, and accessibility testing. Strong strategies map tests to product risk instead of maximizing test count.

## Automation And Maintainability
Automation should be reliable, readable, and tied to stable behavior. Good candidates understand fixtures, test data, mocks, selectors, retries, parallel execution, and why flaky tests damage trust in the pipeline.

## Defect Triage And Debugging
Defect reports should include reproduction steps, expected and actual behavior, environment, logs, screenshots or traces, severity, and likely ownership. Triage balances customer impact, release risk, and engineering effort.

## CI Quality Gates
Quality gates should catch regressions early without blocking teams unnecessarily. Useful signals include test pass rate, coverage of critical workflows, performance thresholds, accessibility checks, and release rollback criteria.
