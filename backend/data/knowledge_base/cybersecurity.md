# Cybersecurity Knowledge Base

## Security Fundamentals
Cybersecurity work starts with assets, threats, trust boundaries, and likely attacker paths. Strong candidates reason about confidentiality, integrity, availability, authentication, authorization, encryption, logging, and secure defaults.

## Web And Application Security
Common web risks include injection, broken access control, cross-site scripting, insecure deserialization, weak session management, and sensitive-data exposure. Secure coding requires validation, output encoding, least privilege, dependency hygiene, and careful error handling.

## Threat Modeling And Testing
Threat modeling identifies what can go wrong before production. Security testing combines code review, dependency scanning, dynamic testing, penetration testing, and abuse-case validation. Findings should be prioritized by exploitability and impact.

## Detection And Incident Response
Good detection uses logs, alerts, anomaly signals, and runbooks. Incident response prioritizes containment, evidence preservation, eradication, recovery, communication, and lessons learned.
